# Ассистент студента — Telegram-бот

Telegram-бот для студентов: расписание занятий, домашние задания, дедлайны и мотивация.

## Возможности

- **Расписание** — вывод расписания на сегодня, завтра или всю неделю с автоматическим определением чётности недели
- **Домашнее задание** — добавление и просмотр ДЗ по предметам
- **Дедлайны** — управление дедлайнами с уведомлениями за 24 часа и 1 час до срока
- **Мотивация** — случайные мотивационные цитаты
- **Автоматические уведомления** — ежедневная рассылка расписания в 08:00

## Поддерживаемые группы

- ИСП-25-1
- ИСП-25-2
- МР-25

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

1. Скопируй `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
2. Открой `.env` и вставь токен бота от [@BotFather](https://t.me/BotFather):
   ```
   BOT_TOKEN=123456:ABC-DEF...
   ```

## Запуск

```bash
python main.py
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация и выбор группы |
| `📅 Расписание` | Просмотр расписания (сегодня / завтра / неделя) |
| `📚 Домашнее задание` | Просмотр и добавление ДЗ |
| `⏰ Дедлайны` | Просмотр и добавление дедлайнов |
| `💪 Мотивация` | Случайная мотивационная цитата |

## Стек технологий
